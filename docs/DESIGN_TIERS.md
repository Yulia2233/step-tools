# STEPIR 的信息分层：哪些必须直接给，哪些可以安全压缩，哪些让 Agent 按需看

> 起因：用户指出，问题不是"计算几何做得太少"，而是要明确 **哪些信息必须直接提供、哪些可以安全压缩、哪些应让 Agent 按需观察**。
> 本文把这条原则变成可检验的判据，并记录每一层目前放了什么、依据是哪项实测。

## 判据（三个问题，按顺序问）

1. **Agent 写代码时每次都要读、而且读错就会写错吗？** 是 → 第一层，直接给。
2. **它能从已给出的内容确定性地重新算出来吗，且重算的结果是唯一的？** 是 → 第二层，压缩掉，但必须保证可还原。
3. **它只在某个具体面或某个具体假设上才有用，或者体积很大/带推测成分？** 是 → 第三层，Agent 按面号按需取（`cand/stepir_query.py`）。

压缩的底线：**不丢信息，只丢冗余**。每一种压缩都对应一个可检验的还原保证（见下表"还原保证"）。

## 第一层：必须直接给（基础 IR，每次都读）

| 内容 | 为什么必须 | 现状 |
|---|---|---|
| 面的载体（平面 o/n，圆柱 p/d/r，圆锥、球、环面及其范围、凸凹 cc） | 建模的直接参数；NURBS 里的解析面必须以解析形式给出，否则 Agent 会去拟合样条 | 样条面重新识别为解析面（解析面项 0.995，特异度 1.0） |
| 平面边界环（L/A/C 链）与棱柱结构（ext/twin/rect） | 草图轮廓就是它 | 样条边认回直线/圆弧后才能编码，且合并共线线段、同心弧 |
| 倒角/圆角行：面、种类、半径、**它圆滑的两个面** | `shared_boundary`/ql 选边的唯一依据，猜错就是 `ql.edge.resolve` | 被 IR 隐含的支撑面，行内直接写载体，不让 Agent 反推 |
| 自由曲面标记 `freeform` | 告诉 Agent 这些面不是拉伸/回转，别去凑 | 非刚体面全部标出 |
| **有证据的**操作来源 `op` | 锥/环/球/样条面只有唯一运动能扫出，是决定性证据 | 只对解释了锥/环/球/样条面的组输出，只列这些面 |

## 第二层：可以安全压缩（确定性派生、可还原）

| 压缩 | 还原保证 | 效果 |
|---|---|---|
| 棱柱侧面不单独列（`implied`） | 侧面 = 盖面环的一条边沿法向的扫掠；只在 `_swept` 校验通过才压缩 | 原有机制，保留 |
| 同一曲面被拆开的碎片合并成一个面 | 合并条件：载体相同（解析面比参数）或沿共享边法向与曲率连续（样条面）；并集边界闭合才合并，否则拒绝合并 | 拆面变体的 IR 恢复到与原件一致 |
| 合并共线线段/同心弧 | 顶点只是邻面拆分留下的 T 型点，不改变形状 | 邻面拆分不再改变平面的环 |
| 圆柱/圆锥/环面的 `op`、`axis` 里的重复字段 | `axis` 的子午轮廓可由载体精确重算；`op` 里 `residual`=0 不写；对圆柱/平面的"既可拉伸又可回转"不写 | 实测：派生行 9.8K → 4.5K token，**评分完全不变** |

## 第三层：按需观察（`stepir_query.py`，Agent 要用时才取）

| 命令 | 返回 | 为什么不放进基础 IR |
|---|---|---|
| `face <id>` | 记录、成员面、样条面的**完整控制网、权重、节点** | 基础记录约 170–200 token，加完整载体 430–1100 token，面越复杂越多；只在要重建这一个面时才需要 |
| `evidence <id>` | cadfit：零空间维数、奇异值、候选运动 | 带推测成分，且只对存疑的面有用 |
| `axis` | 共轴簇与 (z, r) 子午轮廓 | 可从载体重算；只有要做 `revolve_rsolid` 时才需要 |
| `neighbours <id>` | 邻面与沿共享边的相切长度 | 邻接查询按需做 |

## 这套划分被什么检验

- 评测集 `bench/` 里 `stability`/`merge`/`analytic`/`origin`/`blend` 衡量第一层与第二层**有没有丢信息**（压缩后分数不降）。
- `tok_rel` 衡量第一层加第二层的体积（现 0.895，基线 2.46）。
- 第三层不进评分，由查询工具的单元检查保证"取得回来"；它的价值要在 agent 轨迹里验证（见下"未验证"）。

## 未验证（诚实地列出）

- 第三层是否真的减少 Agent 的错误/回合数，需要在 agent 评测里对比"基础 IR"与"基础 IR + 查询工具"，本仓库没有做。
- 放样/扫掠/gordon 的区分：基准里没有"沿曲线轨道的自由曲面扫掠"样本，扫掠规则无法验证，目前只标 `freeform`。
- 圆锥倒角与沉头孔锥面、草图圆角与圆角操作在几何上等价，真值按代码算会把后者记成"误报"，这是标签固有歧义，不是检测器能消除的。
