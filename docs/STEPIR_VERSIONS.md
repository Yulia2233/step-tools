# STEPIR：版本演进与最新版原理

STEPIR 把一个 STEP 零件转成给大模型读的紧凑 B-rep 描述（JSON Lines，一行一个面），模型据此写出用 SimpleCADAPI 重建该零件的 Python 脚本。

本文分两部分：第一部分按时间介绍各个版本改了什么、为什么改；第二部分详细讲最新版（v6，几何归一化）的原理、输出格式和每个阈值的依据。
版本号和日期以代码仓库的提交记录为准；早期轮次的效果数字来自项目的训练记录，最新版的数字来自本仓库的基准与真实零件检验。

---

## 一、为什么需要 STEPIR

真实零件的 STEP 原文有 64K–227K 个 Qwen token，模型读不下，也读不出结构。写建模程序真正需要的是：

- 有哪些面，每个面落在什么曲面上（平面、圆柱、圆锥……及其参数）；
- 平面的边界轮廓（就是草图）；
- 哪些面一起构成一个拉伸/回转特征；
- 数字要四舍五入到合适的位数。

STEPIR 只保留这些，并且**只依赖 SimpleCADAPI 自带的检查器**（`simplecadapi.inspect.brep`），不引入别的 CAD 库。

### v3–v5 与增强 IR 的共同问题

它们都**照抄原始的面分割**。同一个几何体经过不同建模器、导入导出或面分割之后 B-rep 会变，IR 也跟着变：

| 现象 | 原因 | 后果（120 个真实 ABC 零件，原始 stepir） |
|---|---|---|
| 圆柱被存成两个半圆柱、大平面被切成几块 | 周期面在接缝处切开、按面积切分 | 一个特征变成多条记录，token 翻倍（6.6K→12.2K） |
| 所有面都存成 B 样条 | 有的系统导出 STEP 时一律转 NURBS | 表头 `types` 全是 `BSPL`，棱柱压缩失效（`implied=0`），边界环全是样条段，token 2.2 倍 |
| 两者叠加 | | token 4 倍（26.4K） |
| 倒角检测依赖 SDK 提示 | 提示只认解析载体 | 倒角一转 NURBS 就检不出来 |

下面是同一个零件（倒角件 case-071）转 NURBS 前后，原始 stepir 的表头：

```
原件:     {"...","counts":{"face":27,"edge":66},"types":{"PLANE":17,"TORUS":2,"CYL":8},"implied":3}
转NURBS:  {"...","counts":{"face":27,"edge":66},"types":{"BSPL":27},"implied":0}
```

v6 对转 NURBS 后的同一个文件给出的表头与原件一致：`"types":{"PLANE":17,"TORUS":2,"CYL":8},"implied":3`。

## 三、最新版（v6）原理

### 3.1 总流程

```
STEP ─▶ SDK 检查器加载（面、边、邻接、载体参数）
     ─▶ ① 曲面识别：每个 B 样条面，在精确采样点上拟合 平面/球/回转面，认得出就改写成解析载体
     ─▶ ② 边识别：每条 B 样条边，认回 直线/圆弧/整圆
     ─▶ ③ 同曲面合并：相邻且同载体（或 G2 连续的样条）面并成一个，边界重新串环
     ─▶ ④ 边界编码：平面在局部坐标系里写成 L/A/C 链，合并共线线段与同圆弧
     ─▶ ⑤ 棱柱压缩（沿用 v4）：成对底面 ext/twin，侧面省略
     ─▶ ⑥ 排序编号，输出面记录
     ─▶ ⑦ 派生行：倒角圆角（含圆滑的两个面）、有证据的操作来源、自由曲面、共轴簇
     ─▶ 第三层：按需查询（样条控制网、拟合证据、子午轮廓、邻接）
```

①–⑥ 在 `cand/stepir.py` 与 `cand/geomnorm.py`，⑦ 在 `cand/stepir_ops.py`、`cand/blends.py`、`cand/cadfit.py`，按需查询在 `cand/stepir_query.py`。
**所有容差都乘以零件包围盒对角线 `diag`**，与零件尺寸无关。

### 3.2 精确采样

识别不用网格近似，而用曲面本身的一阶导数：

1. 用 OCC 给面三角化（弦高 `1e-4·diag`，不够再细化一次到 `3e-5·diag`），取三角形顶点与重心的 **UV 参数**；
2. 在每个 UV 处调用 `BRepAdaptor_Surface.D1` 得到点 `x` 与偏导 `S_u, S_v`，法向 `n = S_u × S_v / |S_u × S_v|`；面是 `REVERSED` 时取反，得到**外法向**；
3. 退化点（`|S_u × S_v| < 1e-12`，如锥顶、球极）丢弃；
4. 三角化拿不到 6 个点时（小面、细长面），在 UV 包围盒上取 11×11 网格，用 `BRepClass_FaceClassifier` 只留在面内部的点。

每个面只需 8 个以上样本，因为下面的方程是高度超定的；采样上限 400 点。

### 3.3 曲面识别（`recognize_face`）

对一个 B 样条（或 Bezier/其它）面，依次尝试下面三种拟合，第一个通过的就是答案。
通过的标准统一是：**所有采样点到拟合曲面的距离都 ≤ `TOL_REL·diag`（`TOL_REL = 1e-5`）**。没有一个通过，就保留为自由曲面。

**平面。** 对点做 SVD，最小奇异向量是法向 `n`；要求点到平面的最大距离在容差内，**且每个采样法向都与 `n` 平行**（`|N_i·n| ≥ 1−1e-6`）。法向朝向取与采样外法向一致。

**球。** 球面上每条法线都过球心。对每个点，把"点到法线所在直线的距离"写成二次型，求和后得到一个 3×3 线性方程：

```
Σ (I − n_i n_iᵀ) c = Σ (I − n_i n_iᵀ) x_i
```

解出球心 `c`，半径取 `|x_i − c|` 的均值，要求偏差在容差内。

**回转面（圆柱、圆锥、环面）。** 回转面的每条法线都与回转轴相交。沿用 `cadfit` 的旋量方程：面被旋量 `(c, w)` 描述的运动扫出，当且仅当速度场处处与面相切，即对每个采样点

```
n · c + (x × n) · w = 0
```

这是关于 6 个未知数的一个线性方程。把所有点叠成矩阵（坐标先按包围盒中心和 `diag` 归一），零空间里**角向分量 `w` 非零**的方向就是一个绕轴的转动：轴向 `a = w/|w|`，轴上一点 `q = c₀ + diag·(w × c)/|w|²`。

窄面会留下几个接近零的方向，所以取最小的 3 个依次尝试，用下面的"子午线检验"决定：把每个点写成轴向坐标 `z = (x−q)·a` 与到轴距离 `ρ`，

| 子午线 (z, ρ) 的形状 | 曲面 |
|---|---|
| ρ 为常数 | 圆柱，半径 = ρ |
| ρ 是 z 的一次函数 `ρ = ρ₀ + t·z` | 圆锥，半角 `atan|t|`，顶点在 `z = −ρ₀/t` |
| (z, ρ) 落在一个圆上 | 环面，主半径 = 圆心的 ρ，次半径 = 圆的半径 |

**输出参数与原有 IR 一致**，这样识别出的面和原生解析面写法相同：

- 圆柱：`p` 为轴段起点、`d`、`r`、`v=[0,L]`（再经 v5 的 `canon_axes` 统一方向）；
- 圆锥：`d` 取**半径增大的方向**，`p` 为面上半径最小处在轴上的点，`r` 为该处半径，`ang` 为半角，`v` 为母线长度范围；
- 环面：`p` 为管心圆的圆心、`d`、`r`（主半径）、`r2`（次半径）、`v` 为管截面角范围；
- 球：`p` 为球心、`r`；
- 周向范围 `span` 由样本角度的"最小覆盖圆弧"给出，`ref` 是面的周向中点方向；
- 凸凹 `cc`：外法向背离轴（环面背离管心）为 1。

范围（`span`、`v`）用**内部样本 + 边界边上的点**一起测，内部样本单独会低估面的真实范围。

### 3.4 边识别（`recognize_edge`）

B 样条边在原 IR 里写成 `["S",deg,x,y,[mx,my]]`，既长又不可用。v6 沿边取 17 个点（按本次走向排序）：

- **直线**：各点到首尾弦的距离 ≤ 容差，且首尾不重合；
- **圆弧 / 整圆**：点共面（SVD 最小奇异值方向为平面法向），平面内做代数圆拟合 `x²+y² = 2ax + 2by + c`，所有点到圆的距离 ≤ 容差。圆的轴向按点的转向定号，使"起点 → 终点"是绕轴逆时针，这正是原 IR 弧段 `s` 的约定。

认出来的边按原生直线、圆弧的同一路径编码，边界环重新变成 `L/A/C`，`rect` 与棱柱压缩随之恢复。

### 3.5 同曲面连通面合并（`merge_groups`）

只合并**相邻**的面；不相邻的同平面凸台不合并（它们是不同特征）。

**解析面：比载体参数**（容差 `2e-5·diag`）：

| 类型 | 相同的条件 |
|---|---|
| 平面 | 法向同向（`n_a·n_b ≥ 1−1e-8`）且到原点距离相同 |
| 圆柱 | 凸凹相同、轴平行、半径相同、两轴之间距离为 0 |
| 圆锥 | 凸凹相同、轴平行、半角相同、**顶点相同**（顶点由 `p − (r/tan α)·d` 唯一确定） |
| 球 | 凸凹相同、球心与半径相同 |
| 环面 | 凸凹相同、轴平行、主次半径相同、中心重合 |

圆锥最初用"两个可能的顶点任一重合即可"，在真实零件上把一个双锥的上下两半锥错并成一个面；改成唯一顶点后修复。

**自由曲面：比沿共享边的 G2 连续性。** 两个样条面可能来自同一张曲面被切开，也可能是两张仅相切的不同曲面。法向连续不足以区分（离线扫了 6039 对相邻样条面，只看法向的宽松判据会误并 550 多对仅相切的面）。所以在共享边内部的采样点上，要求两侧：

- 外法向一致：`n_a·n_b ≥ 1 − 1e-7`；
- 平均曲率 H 与高斯曲率 K 都一致（相对误差 ≤ 1e-4）。

所有采样点都满足才合并。

**合并后的面：**

1. **边界**：收集所有成员面的边界边，出现两次的边（两成员之间的共享边、或一个面自身的接缝）是内部边，删去；剩下的有向边按"终点接起点"串成闭环（距离容差 `1e-5·diag`）。串不成闭环就**放弃合并**，保留原面。按尺寸排序，最大的环是外环。
2. **线段与圆弧的合并**（`coalesce`）：相邻面被切开会在环上留下多余顶点（直线上的 T 字点、整圆被切成两段圆弧）。连续的共线同向线段并成一段，同圆心同转向的圆弧并成一段（含跨越环起点的情形）；一段首尾闭合的圆弧改写成整圆 `C`。
3. **取值范围在所有成员上重新实测**：两个半环面的识别结果可能轴向相反、角度原点不同，不能把各自的范围直接拼起来。
4. 面积相加，邻接取并集，所有成员的 B-rep 面号映射到同一个 IR id。

### 3.6 棱柱压缩与编号（沿用并加固）

棱柱检测沿用 v4：成对的反向平行平面、边界点平移一致、面积相同 → `ext`/`twin`；侧面只有在"确是底面某条边的扫掠"时才省略。v6 的两处改动：

- 平面的边界点改由**编码后的环**生成（顶点和圆心），而不是 B-rep 的边端点。这样邻面切分留下的多余顶点不再破坏"两底面点集平移一致"的判断。
- 排序键里的面积先取两位小数：对称零件上，面积在第 10 位小数上的差异曾让两次建 IR 的编号不同，导致派生行引用的面号对不上。现在一次调用只建一次 IR，派生分析共享同一套编号。

### 3.7 倒角与圆角（`blends.py`）

在**识别与合并之后**的面上检测，所以倒角存成 B 样条或被切成几块时一样能检出。

**圆角**（圆柱面或环面）：

- 截面圆弧小于 170°（整圈的圆柱是孔或凸台，不是圆角）；
- 与至少两个**类型和它不同**的邻面（圆柱圆角的支撑面不能是圆柱，环面圆角的不能是环面）沿共享边 **G1 相切**（法向一致 `≥ 1−1e-5`，在边内部 3 个点上检验），圆柱圆角要求其中至少两个是平面；
- 取相切边总长最长的两个邻面作为它圆滑的两个面；半径取圆柱半径或环面次半径。

**平面倒角**：一个平面夹在两个彼此不平行的平面之间（与两者法向夹角都在 1°–84° 之间），面积不超过较小者的 75%。
若它的法向等于两面法向的角平分线（误差 < 0.15），就是等距倒角，标为可选边；否则是不等距倒角，仍输出，但标 `uncertain`。

**锥面倒角**：圆锥与一个共轴圆柱、一个垂直于轴的平面都相邻，且径向宽度不超过该圆柱半径的 **30%**。
沉头孔、锥形导入口也满足"与圆柱和平面相邻"，这条尺寸规则用来区分：真实带标签零件上，倒角锥的"径向宽度 / 圆柱半径"中位数 0.06、90% 分位 0.27，而无倒角零件上这类锥面的中位数是 0.63。

**`between`**：它圆滑的两个面。若某个面在 IR 里被省略（棱柱侧面），直接写出它的载体：

```
{"derived":"blend","faces":[17],"kind":"fillet","carrier":"CYLINDER",
 "between":[{"t":"PLANE","o":[-43,0,0],"n":[-1,0,0]},9],"r":0.8}
```

模型拿到这两个面，就可以写 `faceA.shared_boundary(faceB)` 选边，不用猜坐标。

### 3.8 操作来源

**刚体运动（拉伸、回转、螺旋）**：用 3.3 的同一个旋量方程，但在整张面上解零空间：

| 零空间维数 | 含义 |
|---|---|
| 0 | 没有任何刚体运动能扫出 → 只能来自放样、沿曲线轨道的扫掠或样条曲面 |
| 1 | 恰好一种运动（圆锥、环面、一般回转面）→ 决定性证据 |
| 2 | 圆柱：沿同轴的拉伸、回转、螺旋都成立 → 轴确定，操作不确定 |
| ≥3 | 平面或球：几乎任何运动都行，不构成证据 |

残差阈值 `TOL = 3e-4`（按 `diag` 归一）。真实的扫掠面残差在 1e-9 量级，放样出的带扭转曲面残差在 7.5e-4–1.8e-3；旧阈值 2e-3 会把后者误判成拉伸或螺旋。另要求第一个被拒的方向残差至少大 10 倍（`GAP = 10`），否则判为"面太小或太平，无法判断"。
平面和倒角面不作证据，用"能同时解释最多的面"的运动合并分组。

**非刚体：放样还是扫掠。** 扫掠面可写成 `S(s,t) = M(t)·P(s)`：沿轨道的每条等参线都是同一个轮廓经刚体运动得到的拷贝，所以每条等参线上点与点之间的**距离矩阵**不变（刚体不变量）。放样在截面之间改变形状，距离矩阵会变。

对每个自由曲面，分别在 u、v 两个方向各取 6 条等参线、每条 32 个点，计算距离矩阵相对第一条的最大变化（除以最大距离），取两个方向中较小者：

- `≤ 2.5e-3` → **sweep**；
- 否则 → **loft**。

基准上的分布：扫掠面 89% 低于 1e-3，放样面 0% 低于 1e-3、中位数 0.02。注意两个全等截面之间的线性放样在几何上就是拉伸，截面同形平移的蒙皮（gordon）在几何上就是扫掠，这两类无法也不应该区分。

### 3.9 信息分层与输出

依据三个问题决定信息放哪一层（详见 `docs/DESIGN_TIERS.md`）：
写代码每次都要读、读错就写错 → **第一层，直接给**；能从已给内容唯一地重算出来 → **第二层，压缩掉**；只在某个具体面或某个假设上有用、体积大或带推测 → **第三层，按需取**。

**第一层（基础 IR）：**

```
第 1 行  {"unit","bbox","vol","area","counts":{"face","edge"},"types":{类型直方图},"implied":被省略的面数}
```

## 五、局限

- **倒角圆角在真实零件上不比 SDK 原提示更准**（带文件名标签的真实件：倒角件 24/75 对 26/75，圆角件 47/75 对 49/75）。v6 的价值是对表示变化保持不变、支撑面可直接用，而不是检出率更高。
- **自由曲面碎片约 3% 合不上**：OCC 拆分样条面时会重新逼近，沿共享边出现 0.5°–1° 偏差；个别零件整件合不上（case-212，20 对全部未合并）。解析面合并不受影响。
- **几何上等价的操作分不开**：沉头孔与锥形倒角、草图圆弧与圆角操作、全等截面的线性放样与拉伸、同形截面的蒙皮与扫掠。v6 对它们给出的是几何上成立的一种解释，不是建模历史。
- 放样/扫掠阈值来自 OCC 的逼近精度，其他建模器导出的样条误差可能不同，结论是假设性的。
- 第三层按需查询只验证了"取得回来"，**没有在 agent 轨迹里验证**是否减少错误或回合数。
- **与旧版不兼容**：合并后面号变了，派生行格式变了（`axis` 去掉了 `meridian`、`op` 只列证据面），被省略的面也可能不同；用 v5 IR 做的训练数据要重建后才能与 v6 混用。
